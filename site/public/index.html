THE IMPORTANT PART

Your school stuff.
Your computer.

Credentials and cached content stay locally. They are not uploaded to this site, GitHub or a shared class server. Windows protects saved credentials and cache with DPAPI; other systems use private file permissions.

Your agent can send retrieved context to its chosen AI provider. The original services still receive normal sign-in/read requests. This integration does not control your AI provider's retention policy.

Discord defaults to accessible servers and exposed DMs. History is partial. To skip it: node scripts/setup.mjs --sources=teams,bakalari. Browser sign-in stays in a separate local Chrome profile.

No Microsoft admin detour.

The default Teams connection uses your ordinary browser sign-in. Graph API access is optional and has separate consent requirements.
